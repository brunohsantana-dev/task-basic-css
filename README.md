# Wide Coverage Location

Projeto de estudo desenvolvido com HTML e CSS para praticar a construção de uma página responsiva.

A learning project built with HTML and CSS to practice creating a responsive web page.

---

## 🇧🇷 Português

### Sobre o projeto

Página de apresentação de um serviço de viagens compartilhadas, desenvolvida como exercício durante meus estudos no DevClub.

A versão inicial foi adaptada para diferentes tamanhos de tela, com ajustes na disposição dos elementos, imagens, fontes e espaçamentos.

### Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts — Nunito
- Git e GitHub

### O que pratiquei

- Estruturação de páginas com HTML.
- Estilização com CSS.
- Organização do layout com CSS Grid e Flexbox.
- Uso de media queries para tablet e celular.
- Imagens flexíveis e fontes adaptáveis com `clamp()`.
- Criação de commits e uso de branches no Git.

### Responsividade

- **Desktop:** imagem e texto lado a lado.
- **Tablet e celular:** conteúdo organizado em uma coluna.
- **Telas menores:** ajustes adicionais nos espaçamentos e tamanhos de texto.

### Como visualizar

Baixe ou clone o repositório e abra o arquivo `index.html` no navegador.

### Funcionalidades

Este projeto é uma página estática voltada à prática de layout. Os links e o botão de cadastro ainda não possuem funcionalidades implementadas.

## English

### About the project

A landing page for a shared ride service, developed as an exercise during my studies at DevClub.

The initial version was adapted to different screen sizes by adjusting the layout, images, typography, and spacing.

### Technologies used

- HTML5
- CSS3
- Google Fonts — Nunito
- Git and GitHub

### What I practiced

- Structuring web pages with HTML.
- Styling with CSS.
- Organizing layouts with CSS Grid and Flexbox.
- Using media queries for tablets and phones.
- Creating flexible images and responsive font sizes with `clamp()`.
- Creating commits and working with Git branches.

### Responsive design

- **Desktop:** image and text displayed side by side.
- **Tablets and phones:** content arranged in a single column.
- **Smaller screens:** additional spacing and font size adjustments.

### How to view

Download or clone the repository and open `index.html` in your browser.

### Functionality

This is a static page focused on layout practice. Navigation links and the sign-up button do not have functionality implemented yet.
